# 研序 · 论文写作工作台

研序是一个用于管理毕业论文资料和写作进度的 AI Skill。它把原始资料、摘录卡片和论文小节关联起来，帮助作者回查出处、记录待补证据，并在下次协作时接着做。

## 安装

从 [Releases](https://github.com/jessieccc07777-stack/yanxu-skill/releases/latest) 下载附件 `yanxu-skill.zip`。在 Kimi Work 桌面端的技能面板上传 ZIP，选择技能 `thesis-kb`。运行生成脚本的环境需提供 Python 3。

## 开始使用

对 AI 说“初始化论文知识库”，指定项目目录，按提示填写研究背景和期限。打开项目目录中的 `工作台.html`，可以查看七步论文流程、提纲与证据、节点提醒及完整使用说明。

作者负责选题、原文核验和最终判断。工作台展示本地知识库快照，AI 更新项目记录后重新生成。发布包只包含通用指引和脚本。
