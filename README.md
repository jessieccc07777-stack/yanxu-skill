# 研序 · 论文写作工作台

研序是一款用于管理论文写作和其他长期研究项目的 AI Skill，适合需要持续收集资料、分析问题并交付报告的人。

收藏一份材料时，可以记录它能回答哪个问题、依据在哪一页，并把它关联到提纲小节。回到项目时，可以从上次的疑点接着做：哪些判断已有依据，哪些还需要补证，下一步要查什么。AI 协助整理、关联、记录和提醒，作者负责核验来源、取舍证据和形成结论。

**适用场景**

- **论文写作**：内置工作台按论文的七个阶段设计，从建档、选题到正文修改与答辩，可以沿用现成流程。
- **行业跟踪、专题分析和研究报告**：沿用问题清单、资料卡片、来源定位和进度记录，按项目实际交付物安排节点。例如，把一份行业月报关联到待分析的问题，记录还缺哪一期同口径数据，下次更新时直接续查。

## 安装

研序适用于支持本地自定义 Skill 的 AI 工具。该工具需要能加载 `SKILL.md`、读写你的项目目录，并运行 Python 3 脚本。

从[版本发布页](https://github.com/jessieccc07777-stack/yanxu-skill/releases/latest)下载 `yanxu-skill.zip`，按所用工具的方式安装：

- 支持导入技能压缩包时，直接导入 ZIP。
- 使用本地技能目录时，将 ZIP 解压到该目录下的 `thesis-kb` 文件夹，使 `SKILL.md`、`scripts` 和 `references` 位于该文件夹的第一层。

## 开始使用

写论文时，对 AI 说“初始化论文知识库”，指定项目目录，按提示填写研究背景和期限。打开项目目录中的 `工作台.html`，可以查看七步论文流程、提纲与证据、节点提醒及完整使用说明。

做其他研究项目时，可以先告诉 AI 要交付什么、现有资料在哪里、眼下要回答哪个问题。工作台展示本地知识库快照，AI 更新项目记录后重新生成。发布包只包含通用指引和脚本。
